# X Cat Vlog

以一只固定 AI 猫咪为主角，记录它像普通人一样生活的英文短视频实验，优先面向 X。

## 内容方向

- **固定角色，自由生活题材**：工作、游戏、动漫、做饭、股票、网络热梗、热点作为日常背景。
- **8–20 秒短视频**：一个情境、一个即时笑点或反转；不做新闻解说和复杂长漫剧。
- **真实猫咪质感**：外貌长期固定，衣服、道具、场景可以变化；全部为原创内容，不直接搬运其他创作者视频。
