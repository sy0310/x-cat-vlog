# X Cat Vlog

一个以固定 AI 猫咪角色为主角的英文短视频生活账号实验。主要面向 X，也可以用其他短视频平台做对照测试。

## 已确定的内容方向

- **角色驱动，而不是垂直话题驱动**：同一只猫咪以普通人的口吻分享自己的生活。
- **题材自由**：游戏、动漫、上班、吃饭、股票涨跌、网络热梗和近期热门事件都可以自然出现在生活里。
- **呈现方式**：约 8–20 秒的短视频；优先一个生活情境、一个即时笑点或轻微反转。
- **不做**：新闻解说、政治经济分析、纯搬运他人作品、无意义的长篇 AI 漫剧。
- **视觉原则**：猫咪的花色、眼睛、鼻子、体型、尾巴花纹保持一致；服装、配饰、动作和场景可以变化。
